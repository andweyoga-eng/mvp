Feature Request: Health Update in User Profile with Mandatory Upload for Medical Records
1. Feature Overview
* Profile Section Addition: Add a "Health Update" text box in the My Account Profile section.
* File Upload: Allow users to upload medical documents or images in all standard formats (pdf, jpeg, png, docx, etc.) with appropriate file size limits.
* Mandatory Completion: The Health Update section (text ) must be mandatory file upload is optional. * Booking Restriction: Users should NOT be able to book any sessions unless this section is completed.
* Sessions View:
    * Add a dropdown in Profile showing three session tabs: Upcoming Sessions, Completed Sessions, Cancelled Sessions.
    * Connect session data via a Session–User mapping table in the database.

2. Database Schema Requirements
* Users Table:
    * Fields: id, registration method, profile info (name, contact, emergency details, Health Updates), profile state (complete/incomplete).
* Session-User Mapping Table:
    * Maps user_id to session_id and tracks session status for display in sessions view.

3. Admin Console Requirements
* Create a table view listing all registered users.
* Show profile completeness indicators (Complete / Incomplete).
* Allow admins to view session linkages and health update document previews/downloads.
* Provide a separate admin console dashboard link to login and manage these records securely.

4. Inputs & Outputs
* Inputs:
    * User credentials (Google sign-in).
    * Profile fields with mandatory name, contact, emergency details, and Health Updates (text ).
* Outputs:
    * Successfully registered user accounts with fully populated profiles.
    * Correct user-to-session mappings for session history.
    * Admin visibility of compliance and completeness status.
